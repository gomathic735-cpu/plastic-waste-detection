1. PROJECT OVERVIEW

Plastic waste is accumulating across different sections of the lake shoreline, but there is no systematic way to identify high-waste areas and prioritize cleaning.

The proposed project uses Artificial Intelligence and Computer Vision to detect plastic waste from images, count detected plastic waste items, identify waste levels, and support cleaning prioritization.


2. PROBLEM STATEMENT

Plastic waste is accumulating across different sections of the lake shoreline, but there is no systematic way to identify high-waste areas and prioritize cleaning.


3. OBJECTIVES

• Detect plastic waste from shoreline images.
• Identify different types of plastic waste.
• Count detected plastic waste items.
• Identify areas with comparatively higher waste levels.
• Support cleaning teams in prioritizing areas.
• Develop a software-based AI solution for monitoring plastic waste.


4. FIELD OBSERVATION

During field observation, plastic waste was observed along different sections of the lake shoreline.

The observation showed that waste is not uniformly distributed and that systematic identification of high-waste areas can help in cleaning prioritization.

Field photos and videos were collected during the observation.


5. PROBLEM ANALYSIS

Five Whys analysis was used to understand the problem.

Observed issue:
Plastic waste is present across different sections of the shoreline.

Possible contributing factors include:
• Improper disposal of plastic waste.
• Waste carried through drains or runoff.
• Insufficient availability or placement of waste bins.
• Irregular waste collection.
• Lack of systematic monitoring.

These factors are considered possible causes and require further validation.

7. PROPOSED SOLUTION

The proposed solution is an AI-based plastic waste detection and hotspot mapping system.

Basic workflow:

Image Capture
       ↓
Image Pre-processing
       ↓
YOLO11n AI Model
       ↓
Plastic Waste Detection
       ↓
Plastic Waste Counting
       ↓
Waste Level Identification
       ↓
Hotspot Identification
       ↓
Cleaning Prioritization

The system is designed to support human decision-making rather than automatically making cleaning decisions.

11. KEY FEATURES / MODULES COMPLETED

Module 1 – Plastic Waste Detection

The trained YOLO11n model detects plastic waste from input images.

Detected classes:
• Plastic Bag
• Plastic Bottle
• Plastic Glass


Module 2 – Plastic Waste Counting

The system counts the number of detected plastic waste objects in each image.


Module 3 – Basic Waste-Level Identification

A prototype rule-based classification is currently used:

• 0 detections → Low
• 1–2 detections → Medium
• More than 2 detections → High

This is an initial prototype rule and is not considered a validated environmental severity score.


Module 4 – Hotspot Identification Prototype

The system uses the detected waste count to identify comparatively higher-waste images/areas.

Further development is planned to convert this into proper location-based hotspot mapping.

13. MODEL VALIDATION RESULT

The trained YOLO11n model was evaluated on the validation dataset.

Validation results:

Precision: 0.881
Recall: 0.764
mAP@50: 0.836
mAP@50-95: 0.701

Validation set:
238 images
302 object instances

These values represent model validation results on the dataset and should not be interpreted as real-world field accuracy.

17. RESPONSIBLE AI

The system is intended to support human decision-making.

AI predictions may contain errors, especially when images have poor lighting, occlusion, unusual viewpoints, or objects that are difficult to identify.

Cleaning decisions should therefore be verified by responsible human personnel.

The project does not use personal identification as a project objective.
